# WebSocket Chat

Простой чат-комната на базе Express и Socket.IO.  
Пользователи могут входить под любым именем и обмениваться сообщениями в реальном времени.

## Возможности

- Мгновенная отправка сообщений без перезагрузки страницы
- Отображение имени отправителя
- Автоматическая прокрутка новых сообщений

## Технологии

- Node.js
- Express (5.2.1)
- Socket.IO (4.8.1)
- HTML/CSS (встроенные стили)

## Установка и запуск

1. Убедитесь, что установлен [Node.js](https://nodejs.org/) (версия 18+).
