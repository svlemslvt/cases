# Банк Котиков – исправленная версия

Проект представляет собой веб-приложение виртуального банка с чатами, переводами и административной панелью.  
Исходная версия содержала критические уязвимости, которые были выявлены в ходе security-аудита.  
Данный репозиторий содержит **исправленную** версию с подробными комментариями в коде.

## Какие ошибки были найдены и как они исправлены

### Критические (CVSS 8.0–10.0)

| Ошибка | Исправление |
|--------|--------------|
| **Debug mode включён** | Теперь `app.run(debug=DEBUG)` где `DEBUG = os.environ.get('FLASK_DEBUG', 'False')` |
| **Жёстко заданный secret_key** | Берется из `SECRET_KEY` окружения или генерируется `secrets.token_hex(32)` |
| **XSS через подстановку в JS (session.get("peer_id"))** | Удалён опасный код; все данные в шаблонах экранируются через `|e` и `|tojson` |
| **JSON без подписи** | Добавлена HMAC-SHA256 подпись; перед загрузкой/миграцией проверяется |
| **Карточные данные в открытом виде** | Номера карт маскируются (показываются только последние 4 цифры); CVV и сроки не выводятся; при генерации используются криптостойкие ГПСЧ |

### Высокие (CVSS 7.0–7.9)

| Ошибка | Исправление |
|--------|--------------|
| **Отсутствие CSRF** | Внедрён `Flask-WTF` и токены во все формы |
| **Генерация CVV через random** | Заменён на `random.SystemRandom().randint` |
| **Отсутствие транзакций при миграции** | Вся миграция обёрнута в `with conn:` (автокоммит только при успехе) |
| **Нет ограничений длины полей** | Добавлена валидация длины и типа перед вставкой в БД |
| **XSS через атрибут lang** | Добавлен фильтр `|e` во все атрибуты HTML |

### Средние (CVSS 5.0–6.9)

| Ошибка | Исправление |
|--------|--------------|
| **Отсутствие индексов** | Добавлены индексы на `timestamp`, `from_user`, `to_user` в SQLite |
| **`INSERT OR REPLACE` затирает данные** | Заменён на проверку существования и `INSERT OR IGNORE` где нужно |
| **Нет регенерации сессии после логина** | Добавлен `session.clear()` перед установкой новой сессии |
| **Нет контроля доступа к файлам** | В `/uploads/<filename>` добавлена проверка авторизации (можно расширить до проверки прав) |
| **Утечка полных номеров карт в админке** | Выводятся только последние 4 цифры |
| **Предсказуемая дата истечения карты** | Оставлено как есть, но карты теперь маскируются |

### Низкие и информационные

| Ошибка | Исправление |
|--------|--------------|
| **Отсутствие CSP** | Добавлен мета-тег и заголовки (рекомендуется выставить на сервере) |
| **Отсутствие rate limiting** | Добавлен `Flask-Limiter` с ограничением 5 попыток входа в минуту |
| **SHA256 пароли (старые)** | При логине они автоматически заменяются на bcrypt |
| **Стек-трейсы при ошибках** | Отключен debug режим – теперь пользователь не видит трейсы |
| **Нет инвалидации сессии при выходе** | `session.clear()` полностью очищает сессию |
| **Вложенные `<script>` теги** | Исправлена вёрстка, весь JS вынесен в отдельный файл |
| **Генерация favicon на каждом запросе** | Упрощено – favicon теперь статический (не влияет на безопасность) |
